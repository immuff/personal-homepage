# 实际验收记录

验收日期：2026-10-13 至 2026-10-14（Asia/Shanghai）。本文件记录本机运行结果；后续 SSH 部署的实际结果单独记录在 [公网验收](public-verification.md)。

## 实际环境与运行

- Node.js 24.20.0 / npm 11.19.0。
- Next.js 16.4.0、React / React DOM 19.3.0、react-markdown 10.1.0、remark-gfm 4.0.1、@fontsource/lxgw-wenkai 5.3.0。
- 项目独立 Python 3.12.14 虚拟环境；FastAPI 0.143.0、Uvicorn 0.54.0；`pip check` 返回 `No broken requirements found`。
- 使用真实 `next start` 生产服务 3001 和 Uvicorn 8001；数据库为 `backend/data/content.db`。
- 字体包自身提供本地文件，未依赖远程 Google Fonts。用户确认的原 PNG 复制后校验值与源文件一致。

## 页面、接口与操作

| 验收项 | 实际结果 |
| --- | --- |
| 首页、文章、正文、作品、关于 | 本地 HTTP 200；浏览器中分别访问并查看内容 |
| 顶部导航和首页两个入口 | 实际点击，进入相应页面 |
| 文章列表到正文、返回列表 | 实际点击并成功返回 |
| 搜索 `SQLite` | 实际接口与浏览器均返回 1 篇符合标题或摘要的文章 |
| 搜索不存在词 | 接口返回空数组，浏览器出现空结果页；“查看全部文章”恢复 3 篇 |
| 引号、`%`、`_` 和超长输入 | 接口测试确认字面匹配、参数化查询；121 字返回 422 |
| 不存在文章 `/blog/does-not-exist` | 页面与接口均为 HTTP 404；浏览器显示对应设计页面，返回按钮可用 |
| 普通不存在页面 `/no-such-page` | HTTP 404 |
| 作品状态和类别筛选 | 显示“已完成”与“开发中”；点击“游戏”只显示示例游戏 |
| 作品链接 | 指向本站有效首页或文章页，已实际访问 |
| 真实数据链路 | 8001 FastAPI 直连和 3001 `/api` 代理的 profile、posts、单篇正文、projects JSON 完全一致；浏览器读取与搜索结果一致 |
| 数据库刷新 | 临时修改文章标题、个人近况、作品介绍，浏览器刷新后三处均显示 SQLite 中的新值 |
| 后端重启与持久化 | 实际停止 8001 监听进程再重启，三处修改仍保留；随后恢复原始内容 |
| 后端不可用 | 浏览器显示“内容读取失败（HTTP 500）”，没有假内容回退；重启后点击“重新读取”恢复 |

正文由 React Markdown 渲染；代码块、图片、链接和 GFM 表格已在浏览器中看到。原始 HTML 不会被解析为可执行页面。

## 测试与构建

- 后端 `python -m unittest discover -s tests -v`：**5 项通过**，使用独立临时数据库。
- 前端 `npm.cmd test`：**3 项通过**，覆盖真实响应读取、HTTP 错误和网络失败传播。
- `npm.cmd run build`：**生产构建成功**，使用 App Router、常规 Next.js 服务和 rewrites。
