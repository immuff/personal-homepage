# 个人主页与博客首版设计

目标：温和、适合阅读的个人表达空间，兼顾文章、游戏及工具作品展示。使用原创文案；未知资料和作品均标明示例，不添加履历或指标。

视觉：参考李勃老师网站的留白、文字层级和分区节奏。背景 #F2F1EA，强调 #2E7A6E，正文 #151613，次要 #57615A，区块 #F8F7F2，边框 #E2E0D6。中文采用本地霞鹜文楷。导航与页脚统一，内容最大宽度 1040px，文章正文 720px。首页居中介绍、两枚入口、完整人物主图、最近文章、精选作品与近况。头像和主图使用同一份用户 PNG。

架构：frontend 为独立 Next.js App Router / React / CSS 项目，backend 为独立 Python 3.12 / FastAPI 项目；SQLite 使用 Python 标准库 sqlite3。Next.js 服务运行于 3001，rewrites 将 /api/:path* 代理到 127.0.0.1:8001/api/:path*。浏览器请求相对 /api。详情页在服务端读取同源代理并调用 notFound，保证不存在的正文是真正 HTTP 404。

数据：profile（单条 JSON 文档）、posts（slug、标题、摘要、日期、标签 JSON、Markdown、示例标记）、projects（名称、类别、介绍、状态、图片、有效地址、示例标记、精选标记）。所有展示内容由 SQLite 提供。初始化只插入缺失记录，重复初始化不覆盖修改。启动不自动重置或生成数据库。

操作：/ 首页；/blog 查询标题或摘要，使用参数化 SQL 且按字面匹配 %/_；/blog/[slug] Markdown 阅读；/projects 分类展示；/about 个人介绍和资料待补区域。仅实现只读 API，不添加管理后台、登录、评论或发布流程。

失败：网络失败、非成功响应在页面明确显示，支持用户重试；没有静默默认内容。Markdown 不解析原始 HTML；外链明确标明去向。搜索输入最多 120 字，后台边界校验返回 422。

验收：接口契约与搜索测试；页面访问、真实代理数据、搜索/空结果、404；修改 SQLite 后浏览器刷新；后端重启验证保留；桌面/手机布局与 Markdown 长代码；独立生产构建。环境及证据记录在 README 与 docs/verification.md。
